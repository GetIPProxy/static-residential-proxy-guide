# 静态住宅 IP 选购指南：如何选到纯净的静态住宅家宽 IP

**静态住宅 IP（静态住宅代理）**的出口地址在约定的使用期内不变。用 IP 数据库查这个地址，通常会看到家庭宽带或运营商网络的标记。比如每天登录店铺后台，或隔一段时间再跑同一套测试，都可以接着用原来的出口。

如果你需要长期用同一个出口，这套指南会告诉你去哪里查、报告怎么看，以及查到什么结果才适合你的业务。

```

```

## 核心观点

1. **判断 IP 够不够「纯净」，要看五项**。分别核对类型真实性、地理一致性、历史信誉、独占性和长期稳定性。
2. **结果不一样，就换个来源再查一次**。查地区时，先对比几个地理库，再到你实际用的平台看它显示哪儿。
3. **按手头的业务来选**。做本地业务先核对城市，需要独享就问清卖家会不会把同一个 IP 分给其他客户。
4. **到手后存下第一次的检测结果和日期**。这份记录就是「基线」。以后用同样的平台和方法复检，就能看出哪一项变了。
5. **账号出了问题，要分开查出口和账号状态**。平台还可能参考设备、账号资料和操作记录。收到平台通知时，按它的流程处理。
