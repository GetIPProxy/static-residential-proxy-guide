# 静态住宅 IP 是什么？能解决什么、不能解决什么

> **适合谁读**：第一次接触静态住宅 IP，或正替团队拿主意、想知道要不要买的人。这篇也可以当作系列导读。
> **读完你能**：说清静态住宅 IP 是什么，判断自己的业务用不用得上，知道哪些问题得另外解决、哪些用法会越界。
> **阅读时间**：约 15 分钟
> **系列位置**：第 01 篇 · 入口

## 先说结论

- **静态住宅 IP**（也叫静态住宅代理）的出口地址在约定的使用期内不变。用 IP 数据库查这个地址，通常会看到「家庭宽带」或「ISP」一类的标记。ISP 指网络运营商。
- 比如，你今天用电脑登录店铺，明天换手机。只要两次登录都走同一个固定出口，平台看到的就是同一个 IP。
- **适合**：确实需要固定住宅出口的业务。比如长期运营社媒账号、管理店铺或广告账户，也包括本地业务、代运营和需要反复在同一地区做的测试。
- **不适合**：大规模数据采集、API 白名单、一次性浏览、游戏加速，以及任何规避平台规则的用途。
- **账号出问题时，还要查设备、账号资料、付款信息和操作记录。** 这些都可能影响平台的判断。

## 一、什么是静态住宅 IP？

**静态住宅 IP** 是一种代理 IP。用 IP 数据库查，通常会看到家庭宽带或运营商网络的标记。约定的使用期内，出口地址不会换。续费能不能留住原 IP，买之前要问清楚。你可以按产品支持的协议（如 HTTP(S) 或 SOCKS5）连接代理。通过代理访问网站时，网站看到的是代理的出口 IP。

拆开看，有三个关键词：

| 关键词 | 含义 | 和什么相对 |
|---|---|---|
| 静态 | 在约定的使用期内一直用同一个出口 IP | 动态（轮换） |
| 住宅 | IP 数据库通常把这个地址归为家庭宽带或运营商网络 | 机房（数据中心） |
| 代理 | 通过代理访问网站，网站看到的是代理的出口 IP | 直接用本地网络的 IP |

**看产品名称时**，遇到「静态住宅代理」「固定住宅 IP」，先问地址能用多久。看到「ISP 代理」「家宽 IP」或「原生住宅 IP」，还要分别问出口接在哪里、卖家说的「原生」是按哪个报告判断的。第 03 篇会展开讲。

## 二、静态住宅 IP 和其他代理有什么区别？

| | 静态住宅 IP | 动态住宅代理 | 机房代理（数据中心） | 移动代理 | VPN | 云服务器固定 IP |
|---|---|---|---|---|---|---|
| IP 是否固定 | 约定的使用期内固定 | 按请求或按时间轮换 | 通常固定 | 通常轮换 | 可能变化 | 固定 |
| 网络类型 | 通常标为家庭宽带或运营商网络 | 家庭宽带 | 数据中心 | 移动网络 | 多为数据中心 | 数据中心 |
| 是否独享 | 看卖家是否承诺把这个地址单独分给你 | 共享 IP 池 | 可独享 | 多人共享 | 多人共享 | 独享 |
| 常见计费方式 | 按 IP 数量和周期 | 按流量 | 按 IP 数量 | 按流量或端口 | 按订阅 | 按服务器 |
| 典型用途 | 长期运营的账号、店铺、测试环境 | 大规模数据采集、价格监控 | API 调用、对网络属性不敏感的任务 | 移动端相关任务 | 个人隐私保护 | 部署服务、IP 白名单 |
| 相对价格 | 较高 | 按量计费 | 较低 | 较高 | 较低 | 视配置 |

按你要做的事来选。

- **既要住宅或运营商网络的 IP，又要地址固定** → 静态住宅 IP
- **需要按请求或会话换 IP** → 动态住宅代理
- **只要 IP 固定，网络类型无所谓** → 机房代理或云服务器固定 IP

## 三、为什么长期运营的业务需要静态住宅 IP？

有的平台会留意你平时用哪个 IP、从哪儿登录、用的是哪台设备。浏览器、时区和语言设置，以及你平时怎么用这个账号，也可能影响平台的判断。

如果下面这些情况突然出现，平台可能会要求你再验证一次。

- 今天登录时显示在美国，明天显示在日本；
- 同一个出口 IP 突然有多个账号登录；
- 账号平时用的是家庭宽带，这次的出口被标成了机房 IP。

静态住宅 IP 能把登录时用的出口固定下来。要买独享，就看卖家有没有承诺把这个地址单独留给你。平台怎么判断这次登录，还要看设备、账号资料等其他信息。

> **同一个出口，下次登录还能接着用。**

## 五、谁不需要静态住宅 IP？

| 需求 | 为什么不需要 | 更合适的方案 |
|---|---|---|
| 大规模数据采集、价格监控、搜索结果批量抓取 | 如果任务需要多个出口轮换，买一个固定 IP 满足不了这个需求 | 动态住宅代理或机房代理 |
| API 调用、SaaS 或企业网银的 IP 白名单 | 如果对方只要求从白名单里的 IP 接入，普通固定 IP 就够用 | 机房固定 IP、云服务器固定 IP |
| 一次性浏览、偶尔查看某个地区的网页 | 偶尔看一眼，用不着长期留着同一个 IP | 确实要用代理时，可以先看看按量计费的方案 |
| 游戏加速、低延迟需求 | 住宅链路的延迟往往更高、更不稳定 | 游戏加速器或专线 |
| 运营者本人就在目标国家 | 如果手头的网络已经符合业务要求，可以接着用 | 直接使用本地网络 |
| 规避平台地区限制、批量注册、刷量、绕过封禁 | 违反平台规则，也是 IP 被污染的主要来源 | 不提供方案 |

## 六、要不要买：三个问题的决策树

**问题 1：你有没有需要长期管理的账号、店铺或广告账户，或者要反复做的测试？**（替客户运营也算）
- 没有 → 不需要静态住宅 IP。
- 有 → 看问题 2。

**问题 2：你的业务需要住宅或运营商网络的 IP 吗？**
- 不需要，只要求 IP 固定（如 API 白名单）→ 用机房固定 IP 就行。
- 需要，或者还不确定 → 看问题 3。

**问题 3：隔天再用，或者换一台设备时，你还需要用同一个出口 IP 吗？**
- 不需要 → 偶尔看看当地的网页，用不着为固定 IP 付费。确实需要代理时，可以先看看按量计费的方案。
- 需要 → 如果业务还要求用住宅或运营商网络的 IP，就可以考虑买静态住宅 IP。接着读第 02 篇，看看怎么判断一个 IP 是否"纯净"。要是还没弄清楚需不需要这种 IP，先别急着下单。

## 七、静态住宅 IP 不能解决什么？

买了固定 IP，能解决的是出口地址老变的问题。账号还是出问题时，可以接着查下面几项。

**1. 它不能解决账号层面的关联**

平台识别账号之间的关联，依据远不止 IP：

- 一位 Amazon 卖家发帖说，他在 2023 年 3 月就结束了与虚拟助理的合作。2024 年 4 月，他的账号被停用。按他的说法，平台认定他的账号与前助理名下的另一个账号有关联。
- 按 TikTok Shop 美国站的卖家政策，如果两个账号用了同一个手机号、邮箱或其他联系方式，或者共用付款资料、银行账户，平台可能会据此判断账号之间有关联。[TikTok Shop 美国站卖家政策](https://seller-us.tiktok.com/university/essay?anchor_link=EC5F00C9&from=policy&identity=1&knowledge_id=2380042836166443&role=1)

**2. 它不能替代设备和浏览器环境的隔离**

在同一个浏览器会话里切换账号时，网站仍可能读到原来的 Cookie，也可能看到相同的设备和浏览器特征。换 IP 只会改变出口地址。

**3. 它不能决定广告投放地区**

想换广告投放地区，去广告后台改地区定向。[Google Ads 帮助](https://support.google.com/google-ads/answer/1722043?hl=en)

**4. 它不能提升内容流量**

社媒账号的流量主要取决于内容质量、账号行为和平台算法。

**5. 它不能保证平台信任**

ping0 和 IPQualityScore（IPQS）是第三方检测网站，评估的是这个 IP。账号会不会被要求再验证一次，还得看你登录的平台怎么判断。

## 八、合规边界：哪些用法越界

判断一种用法是否合规，可以问三个问题：

1. **资产是真实、合法的吗？** 账号、店铺、客户关系是否真实存在、合法取得？
2. **你获得授权了吗？** 代运营、助理登录客户账号，是否获得了客户的授权？
3. **违反目标平台的条款吗？** 例如，多数电商平台不允许同一主体未经批准开设多个店铺——IP 无法让这件事变得合规。

两个需要特别说明的场景：

- **本地业务**：静态住宅 IP 只服务于真实经营本地业务的人。本地分类信息平台上存在大量虚假房源诈骗，不能用 IP 伪装本地身份误导消费者；
- **规避限制**：用 IP 规避平台的地区限制、绕过封禁、批量注册账号，既违反平台规则，也会让这个 IP 被污染，影响后续所有使用者。

## 九、IP 来源是否合法：住宅代理的灰色供应链

住宅代理行业有一个不太被讨论的问题：**有些"住宅 IP"来自用户并不知情的设备**。

2024 年 5 月，美国司法部宣布，执法人员摧毁了 911 S5 僵尸网络，并在新加坡逮捕了它的管理者。[美国司法部通报](https://www.justice.gov/archives/opa/pr/911-s5-botnet-dismantled-and-its-administrator-arrested-coordinated-international-operation)

- 美国司法部援引起诉书称，受感染设备对应的 IP 地址超过 1900 万个。FBI 称，这可能是有史以来规模最大的僵尸网络。
- 起诉书指控，被告通过 MaskVPN、DewVPN 等 VPN 应用传播恶意软件，把受感染的设备变成住宅代理出口。
- 起诉书还指控，被告把这些代理出口卖给他人使用，有人用它们实施欺诈等违法活动。

IPQS 在介绍住宅代理时也指出：住宅代理 IP 的来源差异很大，有的来自用户主动同意分享带宽，有的来自悄悄捆绑在免费应用、VPN、浏览器扩展中的"代理软件"，还有的来自直接被入侵的设备。

**对你意味着什么**

- IP 的来源说不清，就很难知道卖家是否有权提供这个出口。这个 IP 以前也可能被人用来诈骗。
- 买之前先问卖家，这个 IP 是来自运营商的网段，还是接在别人家宽带上的代理？如果用的是别人家里的网络，对方知道这件事吗？同意把网络给别人用吗？
- **卖家说不清 IP 从哪儿来，就别买。**

## 常见问题

**Q：静态住宅 IP 和 VPN 有什么区别？**
VPN 常用来保护上网隐私。出口 IP 多来自数据中心，可能会换，也可能有多人共用。静态住宅 IP 在约定的使用期内地址不变，IP 数据库通常把它归为家庭宽带或运营商网络。是否独享，要看卖家怎么约定。

**Q：ISP 代理就是静态住宅 IP 吗？**
有的卖家把 ISP 代理也归到静态住宅 IP 里。常见的「ISP 托管」是用运营商的 IP，服务器放在机房。「真实家宽」的出口则接在住户家里的宽带上。买之前先问卖家是哪一种。详见[第 03 篇](03-proxy-ip-labels.md)。

**Q：为什么静态住宅 IP 比机房代理贵？**
运营商网络的 IP 资源比数据中心 IP 稀缺。如果买的是独享 IP，供应商还得在约定的使用期内把这个地址单独留给你。

**Q：一个静态住宅 IP 可以给几个账号用？**
同一品牌的几个账号能不能共用一个 IP，先看平台规定。替客户管账号，还要先确认客户授权。确实需要分开管理的，再单独配出口。

**Q：买了静态住宅 IP，账号就不会被封了吗？**
不会。IP 只解决网络出口这一层的问题。账号是否被验证、限制或封禁，还取决于设备、浏览器环境、账号资料、支付信息、操作行为和平台规则。

**Q：怎么判断一个静态住宅 IP 是否"纯净"？**
本系列看五项：类型真实性、地理一致性、历史信誉、独占性和长期稳定性。查网络类型、地区和滥用记录时，可以换个来源再查一次。独享和续费能不能留住原 IP，要看购买条款。详见[第 02 篇](02-what-is-clean-ip.md)和[第 04 篇](04-ip-checker-platforms.md)。

**Q：怎么判断一个供应商是否靠谱？**
先问 IP 从哪儿来。再问用哪个网站查、哪几项要达标、到手查出来对不上能不能换。最后问清楚续费还能不能用原来的地址。卖家答不清楚，就先别下单。详见[第 03 篇](03-proxy-ip-labels.md)。
