# 什么叫"纯净"的静态住宅 IP？用五维模型读懂一个 IP

> **适合谁读**：准备购买静态住宅 IP、或已经买了但不确定"到底干不干净"的所有人
> **读完你能**：说清"纯净"由哪几部分组成；知道每一部分用什么平台、看哪个字段；知道自己的业务该看重哪几部分
> **阅读时间**：约 12 分钟
> **系列位置**：第 02 篇 · 主线的起点（定义）

---

## 先说结论

- 这套指南从五个方面判断一个 IP 够不够「纯净」：检测站把它归为哪种网络（类型真实性），各家查到的地区是否一致（地理一致性），有没有滥用记录（历史信誉），卖家会不会把同一个 IP 同时分给其他客户（独占性），能不能长期用下去（长期稳定性）。
- 分数低，说明这次查到的风险分低。买之前还得看看这个 IP 显示在哪儿、有没有近期滥用记录、续费后能不能继续用。
- 做社媒运营，往往更关心是不是独享、地址会不会换。做本地业务，可能更在意常用的平台把这个 IP 显示在哪个城市。
- 纯净只解决"出口本身"的问题，**不能保证账号安全，也不代表网速快**。

---

## 一、为什么"纯净"不能只看一个分数

很多人选 IP 的方式是：打开一个检测站，看风控分数，分数低就买。问题在于，每个检测站的分数回答的是**不同的问题**：

- ping0 的「风控值」主要反映这个 IP 有没有扫描、爆破、发垃圾邮件等**恶意行为记录**；
- IPQualityScore 的欺诈分（`fraud_score`）会参考它掌握的欺诈、滥用记录，以及对代理和 VPN 的识别结果；
- 而"这个 IP 定位在哪个城市""有没有其他人同时在用""下个月还是不是这个 IP"，这些分数都不直接回答。

举两个例子（示意，非真实 IP）：

| | IP 甲 | IP 乙 |
|---|---|---|
| ping0 风控值 | 3（极度纯净） | 22（纯净） |
| 各地理库定位 | 有的说达拉斯，有的说休斯敦 | 三个主流库都定位在洛杉矶 |
| 原生 / 广播 | 广播 IP | 原生 IP |
| 共享人数 | 100–1000 | 1–10 |

甲的 ping0 风控值更低。如果你在洛杉矶做本地业务，还想买独享 IP，可以先看乙。三个地理库都显示洛杉矶，ping0 估算关联到的用户也更少。买之前，再看看你实际用的平台显示哪个城市，问清楚卖家是否承诺独享。

这就像买二手房不能只看房龄：房龄新，不代表户型、地段、产权都适合你。

## 二、先想清楚：你买的到底是什么

先想想你平时怎么用这个 IP。比如，你每天都要登录店铺后台，换了电脑也还要接着用。

有的平台会留意你平时用哪个 IP、在哪儿登录、用的是哪台设备。它也可能参考浏览器、时区和语言设置，以及你平时怎么用这个账号。

如果你确实需要固定出口，先问清楚日常登录要用什么类型的 IP，服务期内能不能一直用这个地址。

> **平时登录店铺，都能走同一个出口。**

下单前，把检测结果和购买条款都看一遍。前者帮你核对网络类型和滥用记录，后者告诉你服务期内会不会换 IP、续费能不能接着用。

## 三、纯净的五维模型

| 维度 | 通俗理解 | 它回答的问题 |
|---|---|---|
| ① 类型真实性 | **身份证上的职业** | 看起来是普通宽带用户，还是机房服务器？ |
| ② 地理一致性 | **户口所在地和实际住址是否一致** | 各家查到的地区一致吗？ping0 显示的国家和注册国家一样吗？ |
| ③ 历史信誉 | **信用记录** | 以前有没有被拿去干坏事？最近有没有？ |
| ④ 独占性 | **是不是合租房** | 有没有别人同时在用？有没有被识别成代理？ |
| ⑤ 长期稳定性 | **工作稳不稳定** | 这个 IP 会不会被换掉？它的归属和检测结果会不会频繁变化？ |

下面逐个展开。每个维度都讲清楚：用什么看、常见误解、什么情况算不合格。

### ① 类型真实性：身份证上的职业

**是什么**：这个 IP 被各个数据库认定为哪种网络——家庭宽带、商业宽带、机房（IDC / 数据中心）、移动网络、教育网等。

**打个比方**：这是检测站给这个 IP 填的「网络类型」一栏。比如，一家可能按网络类型写「运营商」，另一家可能按网段用途写「机房」。

**用什么看**

| 平台 | 字段 | 说明 |
|---|---|---|
| ping0 | IP 类型 | 按它对网段用途的判断，标为「家庭宽带」或「IDC 机房」 |
| IPQualityScore | `connection_type` | Residential / Corporate / Education / Mobile / Data Center |
| ipinfo | ASN 类型（AS Type） | ASN 是自治系统编号。isp / hosting / business / education 说的是这个网络的类型 |
| IP2Location | usage type | ISP、DCH（数据中心）、COM（商业）等代码 |

**常见误解**

- **"显示家庭宽带 = 一定是家庭宽带"**：不对。ping0 官方说明，它把所有"非 IDC 机房"的 IP 都标为家庭宽带，商业宽带、校园网也包含在内。
- **"运营商的 IP 就是住宅 IP"**：机房服务器也可以用网络运营商（ISP）的 IP。同一个 IP，ipinfo 的 ASN 类型可能显示为 `ISP`，ping0 的「IP 类型」却显示「IDC 机房」。第 04 篇会讲遇到这种情况该怎么查。

**什么情况算不合格**：多数主流库都判定为机房 / 数据中心。只有个别库判定为机房时，先别急着否定，要查原因（详见第 04 篇的交叉验证方法）。

### ② 地理一致性：户口所在地和实际住址是否一致

**是什么**：包含两层——

1. **各平台定位是否一致**：国家、州 / 省、城市在各个数据库里是不是同一个地方；
2. **注册国家和 ping0 显示的国家是否一致**：按 ping0 的定义，两者一致就标为「原生 IP」，不一致就标为「广播 IP」。

**打个比方**：户口在 A 城、人住在 B 城，偶尔查证件没问题，但如果每次查到的地址都不一样，就会让人起疑。

**用什么看**

| 平台 | 字段 |
|---|---|
| ping0 | IP 位置（附置信度评分）、原生 IP / 广播 IP、注册地历史 |
| IPQualityScore | `country_code`、`region`、`city`、`zip_code`、`timezone` |
| ipinfo、MaxMind、IP2Location | country / region / city |

**常见误解**

- **"某个检测站说在哪就在哪"**：各家地理库的数据来源和更新时间不同，学术与运营商社区的测量都显示，城市级定位的差异相当普遍。正确做法是看多个主流库的多数结论，最后用目标平台自己显示的地区做校验（第 04 篇）。
- **"原生 IP 一定是家庭宽带"**：ping0 也会把一部分本地机房 IP 标为「原生 IP」。要确认产品是不是真实家宽，再问卖家出口接在哪里。

**什么情况算不合格**：查到的国家和业务要求对不上。要用某个城市时，如果各家查得不一样，先看实际使用的平台显示哪个城市，再按买时约定的条件判断。

### ③ 历史信誉：信用记录

**是什么**：这个 IP 过去有没有被用于扫描、暴力破解、发垃圾邮件、恶意注册、欺诈交易等行为；最近一段时间有没有；频率高不高。

**打个比方**：就像查一个人的信用记录。有过逾期，不代表现在一定不靠谱，但最近还在逾期，就要非常谨慎。

**用什么看**

| 平台 | 字段 | 说明 |
|---|---|---|
| ping0 | 风控值 | 基于扫描、爆破、爬虫、对外攻击、垃圾邮件、木马 C&C 等行为的次数和频率打分；越低越好 |
| IPQualityScore | `fraud_score`、`recent_abuse`、`abuse_velocity` | IPQS 网页把 0–39 分列为低风险。`recent_abuse` 显示这次查询有没有报告近期确认的滥用 |
| Scamalytics | Fraud Score、外部黑名单 | 汇总 Spamhaus、Firehol 等公开黑名单的命中情况 |

**常见误解**

- **"家庭宽带就不会有不良记录"**：不对。ping0 明确说明，风控值和是不是家宽没有直接关系。家宽 IP 如果曾被用于恶意行为，风控值同样会高；机房 IP 没有恶意记录，风控值也可能很低。
- **"分数一样低就一样好"**：不同平台的分数量表不同，**不能互相换算**。ping0 的 20 和 IPQS 的 20 不是一回事。

**什么情况算不合格**：多个独立来源都显示高风险，或者出现**近期滥用**记录（例如 IPQS 的 `recent_abuse=true`）。各平台的具体判读区间见第 05、06 篇。

### ④ 独占性：是不是合租房

**是什么**：包含两个相关但不同的问题——

1. **有没有别人同时在用**：卖家会不会把你买的这个 IP 同时分给其他客户；
2. **有没有被识别为代理 / VPN**：检测平台是否已经把这个出口归类为代理网络的一部分。

**打个比方**：合租房里住的人多了，进出的人杂，物业就会多留意。同样，一个 IP 背后关联的用户越多，越像公共代理或 VPN。

**用什么看**

| 平台 | 字段 | 说明 |
|---|---|---|
| ping0 | 共享人数 | 过去 12 个月关联的独立用户数估算值，分 1–10、10–100、100–1000、1000–10000、10000+ 五档 |
| IPQualityScore | `proxy`、`vpn`、`shared_connection` | `shared_connection` 是企业版字段 |
| ipinfo、Scamalytics | Residential Proxy、VPN、Proxy 等标记 | 表示该 IP 是否被识别为住宅代理网络的一部分 |

**常见误解**

- **"共享人数 1–10 就证明是独享"**：1–10 是 ping0 根据过去 12 个月查到的数据估算的档位。它能看到的数据有限。要是页面显示 1000–10000 或更高的档位，再问卖家这段地址之前和现在是怎么分配的。
- **"供应商说独享，就一定独享"**：用户无法直接验证。检测数据只能提供旁证，所以要把"独享"写进购买条件里。

**什么情况算不合格**：共享人数明显偏高；对账号类业务，被多个平台同时识别为代理或 VPN。

### ⑤ 长期稳定性：工作稳不稳定

**是什么**：包含三层——

1. **地址能用多久**：约定的使用期内地址会不会换，续费后还能不能用同一个 IP；
2. **网段记录有没有变**：看宣告这个网段的 ASN、相关企业和注册信息有没有频繁变化；
3. **检测结果有没有变**：下个月用同样的方法再查一次，看看报告显示的城市、网络类型和风险分有没有变化。

**打个比方**：看履历时，改了公司名和换了工作是两回事。查 IP 的历史也一样。先看变的是企业名称、宣告网段的网络，还是注册信息。

**用什么看**

| 来源 | 看什么 |
|---|---|
| ping0 | ASN 历史、企业历史、注册地历史，以及表中的"首次出现"时间。ping0 的说明是：家庭宽带 IP 通常长期固定归属于同一个 ASN 和企业，频繁变动的通常被视为"不干净"的 IP |
| 你自己的检测记录 | 到手时截图存档，之后定期复检对比（第 11 篇） |
| 购买条款 | 购买周期内是否固定、续费能否保留同一 IP、到期多久回收 |

**常见误解**

- **"今天测过没问题，以后就没问题"**：检测结果会变。IPQS 也明确说明，新数据、检测时间和查询设置都可能改变结果。
- **"一直换 IP 直到找到最干净的"**：每换一次，登录用的出口就变一次。已经在用的 IP 偶尔有一项变动，先按第 11 篇的方法复查，再决定要不要换。

**什么情况算不合格**：ASN、企业或注册地历史近期频繁变化；购买条款不保证周期内固定、或续费不能保留同一 IP。

## 四、五个维度怎么一起看：按业务确定权重

不同业务对五个维度的要求差别很大。下表是本系列六类目标人群的权重建议（★ 越多越重要）：

| 人群 | ① 类型真实性 | ② 地理一致性 | ③ 历史信誉 | ④ 独占性 | ⑤ 长期稳定性 |
|---|---|---|---|---|---|
| A 海外社媒账号长期运营者 | ★★★ | ★（国家级即可） | ★★ | ★★★ | ★★★ |
| B 跨境电商店铺运营者 | ★★★ | ★★★（与店铺资料一致） | ★★ | ★★ | ★★★ |
| D 广告账户运营与投放团队 | ★★ | ★★（国家级） | ★★★ | ★★ | ★★★ |
| C 面向特定城市的本地业务运营者 | ★★ | ★★★（城市级、多库一致） | ★★ | ★ | ★★★ |
| E 代运营机构、海外虚拟助理团队 | ★★★ | ★★ | ★★ | ★★★（含批量 IP 的网段分布） | ★★★ |
| F 固定地区的长期功能验证人员 | ★★ | ★★★ | ★ | ★ | ★★★ |

几个值得注意的规律：

- **长期稳定性对所有人都是 ★★★**。这是"静态"住宅 IP 存在的理由。
- **社媒运营者要问清楚是否独享**。几个账号是否需要各用一个出口，先看平台规定和团队的实际需要。
- **本地业务和测试人员最在意"定位"**：他们对城市级精度和多库一致性的要求，远高于其他人。
- **广告投放人员要看滥用记录**。账户有问题时，也要查付款和账户状态。想换广告投放地区，去广告后台改地区定向。

每类人群具体看哪些字段、什么情况必须要求更换，在第 09、10 篇逐一展开。

## 五、纯净的边界：三件"纯净"做不到的事

1. **纯净 ≠ 账号安全**。平台识别账号环境和关联，看的远不止 IP，还包括设备、浏览器、联系方式、支付和收款信息、操作行为等。一个纯净的 IP 只能避免"出口本身"带来的问题。
2. **纯净 ≠ 平台的内部评分**。ping0、IPQS 都是第三方评估，不是电商、社媒或广告平台使用的内部风控分。它们是有用的参考，但不是平台的判决书。
3. **纯净 ≠ 网速快**。风控和信誉评分不测量带宽、延迟和稳定性。需要直播、上传视频的业务，要单独测试连接质量。

## 六、一页清单：拿到一个 IP，按五维过一遍

| 维度 | 检查项 | 怎么查 | 合格标准（经验值） |
|---|---|---|---|
| ① 类型真实性 | 是否被识别为住宅 / ISP | ping0「IP 类型」+ IPQS `connection_type` + ipinfo ASN 类型 | 多数平台不判定为机房 / 数据中心 |
| ② 地理一致性 | 报告显示的国家、州或城市是否符合要求 | 对比 3 个以上地理库，再看 ping0 的原生 / 广播标记 | 先核对国家。业务要认到具体城市，再看实际使用的平台显示哪个城市，并按约定核对原生 / 广播标记 |
| ③ 历史信誉 | 风险分数、近期滥用、黑名单 | ping0「风控值」+ IPQS `fraud_score`、`recent_abuse` + Scamalytics | ping0 风控值 ≤ 25；IPQS 0–39 且 `recent_abuse=false`；不在主要黑名单 |
| ④ 独占性 | 独享条款、共享人数、代理识别 | 看购买条款，再查 ping0「共享人数」、IPQS `proxy` 和 ipinfo / Scamalytics 的住宅代理标记 | 需要独享时，卖家在书面条款里承诺单独分配这个 IP。检测结果用来辅助核对 |
| ⑤ 长期稳定性 | 归属历史、购买条款 | ping0 ASN / 企业 / 注册地历史 + 供应商条款 | 历史无频繁变动；周期内固定、可续费保留 |

记得**截图并标注检测日期**。这既是你判断的依据，也是日后发现变化时和供应商沟通的证据。

## 常见问题

**Q：五个维度都满分的 IP 存在吗？**
有的 IP 能满足五项要求，但通常更贵，可选地区也更少。可以先按业务最在意的两三项筛一遍，再看看其余几项有没有红灯。比如，做本地业务就先确认平台显示的是你要的城市。

**Q：检测站说"纯净"，平台却要求我验证，是 IP 不纯净吗？**
不一定。平台验证的原因可能来自设备、登录行为、资料变更等多个方面。先按第 11 篇的排查顺序逐项排除，不要第一时间换 IP。

**Q：我只想看一个平台，看哪个？**
不建议只看一个。如果一定要先选一个作为主依据：团队或客户习惯看 ping0 的，用 ping0；更关心海外风控评分体系的，用 IPQS。然后至少用另一个平台复核一次（第 04 篇）。
