# 看懂产品标签：ISP、原生、广播、真实家宽、独享到底指什么

> **适合谁读**：正在比较供应商、被"ISP""原生""双 ISP""独享"这些词搞糊涂的人
> **读完你能**：说清 ISP 和原生的区别；把任何一个产品标签拆成四个维度来理解；知道每个宣传词该怎么追问、用哪个字段验证
> **阅读时间**：约 14 分钟
> **系列位置**：第 03 篇 · 主线的"定义"部分

---

## 先说结论

- 网络运营商（ISP）的 IP 可以用在机房里，这类产品常叫「ISP 托管」。同一个 IP 也可以被 ping0 标为「原生 IP」，只要报告显示的国家和注册国家一致。
- 看到产品标签，分开问四件事：是什么网络、查出来在哪儿、有没有别人也在用、地址会不会换。
- **ISP 托管**的服务器在机房，**真实家宽**的出口接在住户家里的宽带上。直播和上传视频更在意上传速度和会不会断线，选之前用实际线路测一下。
- 下单前先问卖家：用哪个网站查？哪几项要达标？到手查出来对不上，能不能换？

---

## 一、为什么你会分不清 ISP 和原生

很多供应商的产品页上，会出现这样一组选项：

> ISP 静态住宅 ｜ 原生静态住宅 ｜ 双 ISP ｜ 广播住宅

看起来像四个并列的"型号"，其实它们描述的是不同的东西：

- "ISP"描述的是这个 IP **属于什么类型的网络、托管在哪里**；
- 「原生」「广播」通常在说注册国家和报告显示的国家是否一致；
- 「双 ISP」通常指两个数据库都把这个地址标为 `ISP`。可以请卖家说清楚是哪两个。

把不同维度的词放进同一个下拉菜单，读者自然会困惑："我到底该选 ISP 还是原生？"——这就像问"我该买三室还是买朝南"，两者并不冲突。

## 二、四个独立的维度

| 维度 | 回答的问题 | 常见取值 | 通俗理解 |
|---|---|---|---|
| ① 网络类型 / 托管方式 | 这是什么网络？设备在哪里？ | 真实家宽、ISP 托管、机房（IDC / 数据中心）、移动网络 | 这个人的"职业"和"办公地点" |
| ② 地理归属 | 注册国家和检测报告显示的国家一样吗？ | 原生、广播 | "户口"和"实际住址"是否在同一个国家 |
| ③ 独占性 | 有没有别人同时在用？ | 独享、共享 | 整租还是合租 |
| ④ 地址是否固定 | IP 会不会变？ | 静态（固定）、动态（轮换） | 长期住一个地方，还是经常搬家 |

本系列讨论的都是**静态**（维度 ④）IP。下面重点讲维度 ① 和 ②。

### ① 网络类型 / 托管方式

| 类型 | 是什么 | 特点 |
|---|---|---|
| **真实家宽** | 出口设备接在住户家里的宽带上，IP 由运营商分配给这条宽带 | 连接受这条宽带影响，可能会断线。直播或上传前，先测上传速度 |
| **ISP 托管** | IP 段来自运营商，服务器放在机房 | 上下行速度可能更接近，实际速度和连接是否稳定要看线路。有的检测站会把它标为机房 IP |
| **机房（IDC / 数据中心）** | IP 属于托管服务商或云服务商，服务器在机房 | 价格往往较低，检测站也比较容易把它标为数据中心。连接稳不稳，要看具体线路 |
| **移动网络** | IP 来自手机运营商网络，通常大量用户通过运营商级 NAT（CGNAT）共用公网 IP | 共享程度高；一般不属于静态住宅的范畴 |

### ② 地理归属：原生与广播

本系列采用 ping0 的定义：

- **原生 IP**指注册国家和 ping0 显示的国家一致的地址；
- **广播 IP**指这两个国家不一致的地址。例如一些跨国服务商购买大段 IP，再广播到不同国家使用。

两个容易误解的地方：

1. **原生不等于家宽**。大部分家宽 IP 是原生的，但本地机房服务商的 IP 也可能是原生的；
2. **广播 IP 不一定"坏"**，但它的定位更容易在不同平台之间出现分歧，也可能随数据库更新而变化。对需要稳定城市定位的业务，广播 IP 通常不合适。

## 三、组合起来看：一张矩阵

把维度 ① 和 ② 组合起来，就能看清常见产品标签落在哪里：

| | 原生 | 广播 |
|---|---|---|
| **真实家宽** | 最接近普通家庭用户的形态 | 少见 |
| **ISP 托管** | 常见于"ISP 静态住宅""原生静态住宅"等产品 | 常见于价格较低的"广播住宅"类产品 |
| **机房** | 本地机房服务商的 IP | 跨国云服务商、托管商的 IP |

从这张表可以看出：

- **"ISP 静态住宅"和"原生静态住宅"可以同时成立**。ISP 托管说的是出口怎么接。只要注册国家和 ping0 显示的国家一致，它也可以被标为「原生 IP」；
- 它们**也可能互相矛盾**：一个标着"ISP 静态住宅"的产品，可能是广播的；一个标着"原生"的产品，可能其实是本地机房的 IP；
- 所以，**看到任何标签，都要追问它在每个维度上分别是什么**。

## 四、ISP 托管 vs 真实家宽：差在哪

这是选购静态住宅 IP 时最值得弄清的一组区别。

### 1. 物理与体验上的差异

| | ISP 托管 | 真实家宽 |
|---|---|---|
| 出口设备在哪 | 机房 | 真实的住户网络 |
| 稳定性 | 机房接入一般较稳，到手后用实际线路测 | 受家庭网络影响，可能断线或重连 |
| 速度 | 上下行速度可能更接近，以实测为准 | 上传带宽通常较小，直播前最好先测 |
| 属性真实性 | IP 归属于运营商，但部分平台可能识别出机房属性 | 最接近普通家庭用户 |
| 可选地区 | 取决于供应商的机房和合作资源 | 取决于真实住户网络的分布 |
| 价格 | 相对较低 | 通常更高 |

### 2. 在检测数据上可能出现的差异

下面是一些常见的倾向，**不是绝对的判断标准**，需要结合多个平台一起看：

| 观察点 | ISP 托管型可能的表现 | 真实家宽型可能的表现 |
|---|---|---|
| ping0「IP 类型」 | 可能显示家庭宽带，也可能显示 IDC 机房（ping0 按 IP 段实际用途标注） | 通常显示家庭宽带 |
| 部分平台的代理 / 服务器标记 | 可能被个别平台按网段归入服务器或数据中心类 | 较少 |
| 平台之间类型结论 | 更容易出现分歧 | 较一致 |
| 延迟抖动 | 可能较小，用实际线路测 | 受住户线路影响，用实际线路测 |
| 上传带宽 | 看机房线路和购买的套餐 | 看住户宽带的上传速度 |

### 3. 按场景怎么选

| 场景 | 更适合 | 原因 |
|---|---|---|
| 直播、频繁上传视频 | 可先试 ISP 托管 | 用实际线路测上传速度和长时间连接会不会断 |
| 大促期间需要稳定在线的店铺 | 可先试 ISP 托管 | 大促前确认线路能稳定连接 |
| 业务明确要求家庭宽带 | 先核实真实家宽，或团队认可的 ISP 托管 | 先问清出口接在哪里，再按业务约定的检测结果选 |
| 本地化测试、需要可复现的测试环境 | 可先试 ISP 托管 | 先确认能否留住同一个地址，再记录报告显示的地区 |
| 团队或客户要求 ping0 显示「家庭宽带」 | 选报告上显示「家庭宽带」的 IP | 先按约定核对标签。如果还要求真实家宽，再问出口接在哪里 |

无论选哪种，最终都要回到第 02 篇的五维模型去检测，而不是只看产品名。

## 五、"Native"的三种含义

很多供应商用"Native"或"原生"来命名产品，但它可能指三种不同的东西：

| 含义 | 指的是 | 你应该追问 |
|---|---|---|
| 原生地区 | 注册国家和报告显示的国家相同 | "ping0 上显示为原生 IP 吗？注册地历史稳定吗？" |
| 真实家宽 | IP 实际用在家庭宽带里 | "这是 ISP 托管还是真实家宽？ping0 的 IP 类型显示什么？" |
| 非数据中心 | 不是云服务商、托管商的 IP | "主流平台的类型结论是什么？" |

如果供应商说不清自己的"原生"指哪一种，就按三个问题逐一核实。

---

## 六、"双 ISP"是什么意思

"双 ISP"通常指：**两个 IP 数据库都把这个 IP 标为 ISP**（而不是机房或托管）。

这个说法只告诉你两家数据库怎么分类。ping0 举过一个例子，运营商的 IP 用在机房服务器上，页面照样可以显示「IDC 机房」。

想买真实家宽，再问卖家这个出口是不是接在住户家里的宽带上。

## 七、宣传词速查表

| 宣传词 | 真实含义 | 你应该追问什么 | 用哪个字段验证 |
|---|---|---|---|
| 原生 | 见第五部分，可能有三种含义 | 指哪一种？ | ping0「原生 IP / 广播 IP」「IP 类型」 |
| 双 ISP | 两个数据库都标为 ISP | 是 ISP 托管还是真实家宽？ | ping0「IP 类型」、IPQS `connection_type`、ipinfo ASN 类型 |
| 真实家宽 | 出口接在住户家里的宽带上 | 出口接在哪里？断线怎么处理？ | 先问卖家出口在哪，再看 ping0「IP 类型」并实测上传速度 |
| 独享 | 卖家在约定的使用期内把这个 IP 单独分给你 | 有没有书面承诺？发现卖给了其他客户怎么处理？ | 先看购买条款，再用 ping0「共享人数」辅助核对 |
| 纯净 | 没有统一标准 | 以哪个平台、哪些指标为准？ | 按约定的平台和指标检测 |
| 城市级定位 | 能选择城市 | 以哪个数据库为准？定位不准能不能换？ | 多个地理库 + 目标平台显示的地区 |
| 99.9% 在线 | 供应商对可用性的承诺 | 如何计算？达不到怎么补偿？ | 自己记录连接情况 |
| 不限流量 | 不按流量计费 | 带宽有没有上限？ | 实测速度 |
| 长期固定 | 周期内 IP 不变 | 续费能否保留同一个 IP？到期多久回收？ | 购买条款 |

## 八、下单前，把"纯净"的判定依据问清楚

比如，买家用 5 个网站查，都显示为机房。卖家说 ping0 显示的是原生住宅，还说只有连不上才能退款。遇到这种情况，先看下单时约定了用哪个网站、看哪几项。

下单前把下面几件事问清楚，把卖家的答复存下来。

1. **以哪个平台为准？** ping0、IPQS，还是其他平台？
2. **以哪些指标为准？** 例如 ping0 风控值在什么范围内、IPQS `fraud_score` 在什么范围内、是否要求 `proxy=false`。
3. **检测结果在购买时能看到吗？** 是下单前就展示，还是到手后自己测？
4. **不达标能不能换？** 换的条件是什么？只有"无法连通"才能换，还是检测不达标、定位不符也能换？
5. **周期内是否固定？续费能否保留同一个 IP？** 到期后多久回收？
6. **IP 来源是什么？** ISP 托管、真实家宽，还是其他？

到手后，按约定的平台和指标检测一次，截图并标注日期。这既能确认是否符合约定，也是日后沟通的依据。

## 常见问题

**Q：我该选 ISP 还是原生？**
先问卖家出口接在住户家里还是机房。业务还要求地区稳定的话，再查 ping0 的原生 / 广播标记，并核对你实际用的平台显示的地区。

**Q：广播 IP 一定不能用吗？**
不一定。如果你的业务只需要国家级定位，且对价格敏感，广播 IP 可以考虑。但如果需要城市级定位，或者团队以 ping0 的原生标记为标准，就不适合。

**Q：ISP 托管的 IP 被某个平台识别为机房，是不是被骗了？**
ISP 托管的服务器在机房，有的检测站会把它标成机房 IP。先看看买之前说好用哪个网站查、哪些项目要达标，再拿结果跟卖家核对。

**Q：真实家宽一定比 ISP 托管好吗？**
先看你拿来做什么。需要住户家里的宽带，就问清楚出口接在哪里。要直播、上传视频或长时间在线，两种都用实际线路测一遍，再看上传速度和会不会断线。
